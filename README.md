## 👋 About Me

I'm a full-stack software engineer with **2 years of professional experience** building and shipping production web applications, from database design and APIs to polished, responsive front ends. I work across **TypeScript, PHP and Python**, with **Next.js, React and Node.js** as my core web stack, and I'm expanding into **AI/ML, computer vision and RAG**-based assistants.

I've delivered internal enterprise systems end to end, working through requirements, UAT and a structured SDLC to get them into users' hands. I care about maintainable code, clear architecture and software that solves real operational problems.
